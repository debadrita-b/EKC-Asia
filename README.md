# Economic Growth and CO₂ Emissions in Asia

## Environmental Kuznets Curve Analysis, 2000–2023

### Overview

This project examines the relationship between economic development
and CO₂ emissions per capita across 16 Asian countries over 2000–2023.

The analysis combines Python for data collection and cleaning,
Stata for panel-data econometrics, and Tableau for interactive
visualization.

### Research Question

Does the relationship between economic growth and CO₂ emissions
exhibit the nonlinear pattern associated with the Environmental
Kuznets Curve?

### Sample

16 Asian countries
2000–2023
384 country-year observations
Balanced panel

### Methodology

- Data collection and cleaning in Python
- Descriptive statistics and correlation analysis
- Panel unit-root tests
- Panel cointegration investigation
- Dynamic Panel ARDL / PMG estimation
- Static FE and RE benchmarks
- Cross-sectional dependence testing
- Serial-correlation testing
- Driscoll–Kraay robustness analysis
- Tableau visualization
